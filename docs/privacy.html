Privacy policy

Last updated: 25 September 2026

Who uses this app

jeremy-gdrive-backup is a private tool. Its owner is its only user. It is not available to anyone else.

What data it accesses

With the owner's consent, the tool reads files in the owner's own Google Drive. It uses the read-only Drive scope. It does not write, change, or delete anything in the owner's Google account.

How the data is used

The tool uses the data only to make a backup copy on an external disk that the owner keeps. The tool runs on the owner's own computer. No server receives the data.

Sharing

No data is shared with, sold to, or transferred to any third party.

Storage and deletion

Backup copies are stored only on the owner's external disk. OAuth tokens are stored on the owner's computer. The owner can revoke access at any time at myaccount.google.com/permissions. Revoking access removes the tool's ability to reach the account.

Google API Services User Data Policy

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions: the owner's email address is listed on the Google OAuth consent screen for this app.
